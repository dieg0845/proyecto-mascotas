## Sistema de Gestión de Mascotas
Descripción:
Aplicación desarrollada en React que consume una API REST para gestionar mascotas y comentarios.
Permite:

-Listar mascotas.
-Ver el detalle de una mascota.
-Registrar nuevas mascotas con imagen.
-Actualizar el estado de una mascota.
-Eliminar mascotas.
-Agregar comentarios.
-Eliminar comentarios.


--Uso de Inteligencia Artificial--

Durante el desarrollo se utilizó ChatGPT como herramienta de apoyo en distintas etapas del proyecto. Su aporte fue principalmente orientativo para comprender conceptos y proponer alternativas de implementación.

Se utilizó para:

-Explicación del uso de FormData para enviar imágenes mediante Axios.
-Sugerencias para limpiar el formulario después de registrar una mascota utilizando useRef.
-Orientación sobre la comunicación entre ComentarioForm y MascotasDetail mediante props (onAdd).
-Orientación para obtener las opciones desde el endpoint GET /api/choices/.
-Sugerencias para implementar la actualización del estado utilizando el método PATCH.
-Consultas sobre el manejo de errores HTTP (400 y 404) entregados por la API.
-Apoyo en algunos aspectos del diseño utilizando clases de Bootstrap y reorganización de la navegación.
